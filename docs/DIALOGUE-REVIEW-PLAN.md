# 대화 복습 시범 · R1

## 결정한 범위

- 기존 **5단계 「있다와 없다」와 10단계 「이동과 교통」은 그대로 둔다.** 문장 번호와 기존 진도도 바꾸지 않는다.
- 번호 없는 대화 복습 **`R1` 한 개만** 5·6단계 사이에 둔다. 가로 목록과 PC 왼쪽 목록 모두 `R1`로 표시한다. 뒤 단계의 번호는 밀지 않는다. 10단계 뒤의 두 번째 대화는 `R1`을 써 본 다음에 결정한다.
- `R1`은 같은 하루의 이어지는 **다섯 장면(`#1`~`#5`) 71발화**다. 한 장면 10발화로는 다섯 단계에서 배운 말을 담을 자리가 모자랐다 (2026-09-29에 늘렸다).
  체크인 → 방 안내 → 친구와 통화 → 동네 둘러보기 → 내일 계획 순서로, 앞 장의 인물과 말이 뒤 장에 다시 나온다.
  등장인물은 넷이다: 여행자 김민수, 숙소 직원, 친구 다나카, 동네 사람. 장마다 그 장에 나오는 인물만 소개한다.
- 대화에 쓰는 말은 **1~5단계 범위**로 묶는다. 동사(9단계)·숫자(7단계)·시각과 값(8단계)은 쓰지 않고, 명사문·형용사·`あります`/`います`와 조사 `は の か も に が` 안에서 장면을 잇는다.
  연결에 꼭 필요한 미학습 표현은 단어·표현 설명에서 「미리 보는 표현」으로 밝힌다.
- 첫 시범은 읽고 듣는 콘텐츠다. 빈칸 맞히기, 이어질 답 고르기, 3회차 가림은 넣지 않는다. 읽기 완료가 기존 문장 퀴즈의 정답 기록이나 별을 대신하지 않는다.

## 화면 흐름

1. 맨 위에 하루 전체의 상황과 인물 넷을 한두 줄로 소개한다. 그 아래 장(`#`)마다 제목·상황·그 장의 인물을 낸 다음 카드에 **일본어 발화를 처음부터 끝까지** 화자 순서대로 이어서 보여 준다. 한국어를 발화 사이에 끼우지 않는다. 각 발화에는 기존 일본어 음성 재생 기능을 붙인다.
   음성 단추의 번호(`data-i`)는 장을 넘어 0부터 통짜로 이어 센다. 납작한 배열을 만드는 `dialogueTurns()` 하나로 찾으므로 장 순서를 바꿔도 어긋나지 않는다.
2. 대화가 끝난 다음 `한국어 번역` 접기를 둔다. 기본은 닫힘. 열면 일본어와 **같은 장 순서·발화 순서·화자 표시**로 번역 전체를 보여 준다. 장 제목도 같이 낸다.
3. 그다음 `대화 속 단어·표현` 접기를 둔다. 기본은 닫힘. 대화에 실제 나온 핵심 어휘와 표현을 중복 없이 정리하고, 현재 문장별 「더 배워보기」에서 유용한 쓰임·주의·말투 설명을 모은다. 마지막에 `대화 예절·문화`를 짧게 덧붙인다.
4. 맨 아래 `대화 읽음` 단추로 이 복습 한 건의 완료를 표시한다. 번역과 단어 접기를 여는 것은 완료 조건으로 강제하지 않는다. 다시 열어 읽을 수 있다.

번역과 단어 접기는 화면에 들어올 때마다 닫힌 상태로 시작한다. `<details>/<summary>`를 써서 터치·키보드·화면 읽기 도구에서 같은 순서로 접근하게 한다. 일본어에는 `lang="ja"`, 한국어에는 `lang="ko"`를 붙인다. iPad에서 본문과 하단 영역이 겹치지 않도록 접힌 상태와 펼친 상태 모두 확인한다.

## 대화 원고

| 복습 | 장면 | 회수할 말 | 더 배워보기·문화 메모 |
|---|---|---|---|
| `R1 #1` | 프런트에서 체크인 | 인사·자기소개, `の`, `も`, `予約があります` | `すみません`의 쓰임. 일본정부관광국 자료로 확인 |
| `R1 #2` | 방을 안내받다 | い·な형용사, 꾸미는 꼴, 방 설비의 `あります`·`に` | `トイレ`와 `お手洗い` 표기. 국제교류기금 『이로도리』로 확인 |
| `R1 #3` | 친구와 통화 | `どう`, 위치의 `の`, 휴일·시간·`暇`, `います` | 전철·버스에서는 통화를 삼간다. 일본정부관광국 자료로 확인 |
| `R1 #4` | 숙소 주변을 둘러보다 | 지시어, `右`·`左`, 가게·시설 이름, 사람·동물의 `います` | 길을 물을 때도 `すみません`으로 시작한다 |
| `R1 #5` | 내일 계획을 세우다 | `どちら`, 지도·표·날씨, 형용사의 부정, `に`+`あります` | — |

대화의 일본어와 한국어는 발화별로 짝을 맞추고, 문장 사이의 흐름과 화자별 말투를 검토한다. 단어장은 실제 등장 어휘에서 고르고, 기존 `WORDS[].f`와 문장 `s.t`의 설명을 장면에 맞게 간추린다. 문화·예절 설명은 단정적인 일반화를 피하고 신뢰할 자료로 확인한다. 대화 원고의 일본어 화자 검수는 시범 사용 전에 남은 확인 항목이다.

## 구현 순서와 저장 경계

1. **콘텐츠 데이터:** 기존 `SENT[5]`, `SENT[10]`과 각 문장의 `n`은 손대지 않는다. `src/dialogues.js`에 `R1`의 화자 이름과 `chapters[{title,scene,cast,turns}]`, 단어 키, 설명, 문화 메모를 둔다.
   발화는 장 안의 `turns`에만 둔다. 화면·검사기는 모두 장을 훑어 납작하게 만든 배열을 쓰므로, 장을 더하거나 줄여도 화면 코드를 고치지 않는다. 기존 문장에 없는 새 대화이므로 완료 기록은 문장 번호 대신 `R1`로 식별한다.
2. **화면·이동:** 가로 단계 목록과 PC 왼쪽 목록에 복습 항목을 지정 위치에 끼운다. 현재 화면은 번호 있는 단계와 복습 항목을 구별하는 식별자로 다룬다. 단계 번호에 `+1`을 하는 축하 화면의 「다음 단계」, 좌우 화살표 이동, 새로 열었을 때의 화면 복원도 실제 목록 순서를 따르게 한다. 기존 `ST.lv`의 숫자 뜻과 오답노트 식별자 `61`은 유지한다.
3. **완료·동기화:** `R1`의 읽음 여부를 기존 `done`·`QDONE`·`star`와 분리해 저장한다. 복습 화면에는 `읽음`만 표시하고 `0/50`, 회차, 왕관 별을 표시하지 않는다. 기기 간 병합은 읽음 여부의 합집합으로 처리한다. 수동 진도 코드에는 선택 필드로 덧붙여 예전 `J2/J3` 코드를 읽을 수 있게 한다. 예전 코드의 가져오기가 이미 기록된 `R1` 읽음을 지우지 않는다.
4. **검증·배포:** 데이터 검사에서 장마다 제목·상황·화자, 장별 6발화 이상과 전체 40발화 이상, 발화별 화자·일본어·번역 누락, 단어 키의 사전 존재와 실제 등장, 중복, 문화 메모 출처를 확인한다.
   「暑い」가 「暑くないです」로만 나오는 것처럼 활용해 등장하는 말이 있어 어미(`い`·`な`·`です`·`ます`)를 떼고 찾는다. `node tools/check.js`, `node tools/dialogue-test.js`, 동기화 검사를 거쳐 빌드한다. 좁은 휴대폰, iPad 가로·세로, PC에서 접기·스크롤·음성 재생·오프라인 열기와 기존 5단계 진도를 확인한다. 이 환경의 브라우저 실행이 막혀 실제 화면·터치 확인은 아직 남았다.

첫 시범의 크기는 **데이터와 화면에 별도 경로를 만드는 보통 수준의 작업**이다. 특히 이동 순서와 진도 코드·동기화가 숫자 단계에 기대고 있어, 화면만 추가하는 것으로 끝나지 않는다.

## 통과 조건과 이후 판단

- `R1`이 5·6단계 사이에 보이고, 10·11단계 사이는 기존대로다. 1~60단계의 번호와 기존 퀴즈 진도는 그대로다.
- 일본어 대화가 먼저 끝까지 보이고, 한국어 번역과 단어·표현은 **그 순서대로**, 각각 닫힌 채 이어진다. 번역의 장·화자·순서는 원문과 일치한다.
- 장(`#`) 제목과 상황이 장마다 보이고, 소개하는 인물은 그 장에 실제로 나오는 사람뿐이다. 음성 단추는 첫 장 첫 발화부터 마지막 장 마지막 발화까지 빠짐없이 이어진다.
- 단어·표현 접기에 대화에서 나온 말의 뜻·쓰임, 필요한 「더 배워보기」, 검수된 예절·문화 메모가 들어간다.
- 읽음 표시가 새로고침·기기 간 동기화·코드 가져오기 뒤에도 유지되며, 예전 코드도 정상적으로 들어온다. 읽음 표시만으로 퀴즈 별이 늘지 않는다.
- 실제 휴대폰과 iPad에서 본문·번역·단어장 및 하단 영역이 겹치지 않는다.

시범을 써 본 뒤에는 대화가 자연스럽게 읽히는지, 접힌 번역·단어장을 이용하는지, 한 장면의 길이와 다섯 장 전체의 길이가 적절한지 확인한다. 71발화가 한 번에 읽기에 길면 장을 줄이거나 장마다 접기를 두는 쪽을 고려한다. 학습 효과는 읽음 횟수만으로 판단하지 않는다. 10단계 뒤 복습과 5단계 간격 확대, 회상 문제 추가 여부는 그 뒤에 결정한다.
