# 대화 복습 시범 계획

## 결정한 범위

- 기존 **5단계 「있다와 없다」와 10단계 「이동과 교통」은 그대로 둔다.** 문장 번호와 기존 진도도 바꾸지 않는다.
- 번호 없는 대화 복습 `R05`를 5·6단계 사이에, `R10`을 10·11단계 사이에 추가한다. 단계 목록에는 각각 「5단계 복습 · 대화」, 「10단계 복습 · 대화」처럼 표시한다. 뒤 단계의 번호는 밀지 않는다.
- 각 복습은 2~3명이 한 장면에서 나누는 **8~12번의 발화**로 시작한다. `R05`는 1~5단계, `R10`은 1~10단계에서 배운 말이 중심이다. 자연스러운 연결에 필요한 미학습 표현은 소수만 쓰고 단어·표현 설명에서 「미리 보는 표현」으로 밝힌다.
- 첫 시범은 읽고 듣는 콘텐츠다. 빈칸 맞히기, 이어질 답 고르기, 3회차 가림은 넣지 않는다. 읽기 완료가 기존 문장 퀴즈의 정답 기록이나 별을 대신하지 않는다.

## 화면 흐름

1. 장면의 장소·상황과 등장인물을 한두 줄로 소개한다. 대화 본문에는 **일본어 발화를 처음부터 끝까지** 화자 순서대로 이어서 보여 준다. 한국어를 발화 사이에 끼우지 않는다. 각 발화에는 기존 일본어 음성 재생 기능을 붙인다.
2. 대화가 끝난 다음 `한국어 번역` 접기를 둔다. 기본은 닫힘. 열면 일본어와 **같은 발화 순서와 화자 표시**로 번역 전체를 보여 준다.
3. 그다음 `대화 속 단어·표현` 접기를 둔다. 기본은 닫힘. 대화에 실제 나온 핵심 어휘와 표현을 중복 없이 정리하고, 현재 문장별 「더 배워보기」에서 유용한 쓰임·주의·말투 설명을 모은다. 마지막에 `대화 예절·문화`를 짧게 덧붙인다.
4. 맨 아래 `대화 읽음` 단추로 이 복습 한 건의 완료를 표시한다. 번역과 단어 접기를 여는 것은 완료 조건으로 강제하지 않는다. 다시 열어 읽을 수 있다.

번역과 단어 접기는 화면에 들어올 때마다 닫힌 상태로 시작한다. `<details>/<summary>`를 써서 터치·키보드·화면 읽기 도구에서 같은 순서로 접근하게 한다. 일본어에는 `lang="ja"`, 한국어에는 `lang="ko"`를 붙인다. iPad에서 본문과 하단 영역이 겹치지 않도록 접힌 상태와 펼친 상태 모두 확인한다.

## 대화 원고

| 복습 | 장면 초안 | 회수할 말 | 더 배워보기·문화 메모 후보 |
|---|---|---|---|
| `R05` | 숙소에서 방과 주변 편의시설을 묻고 확인하기 | 인사, 장소 질문, 형용사, `あります/います`, `に/が` | `トイレ`와 `お手洗い`의 쓰임, 상대를 부를 때의 말투. 실제 대화에 넣은 표현만 싣고 사실 관계를 검수한다 |
| `R10` | 역에서 목적지로 가는 열차·승강장을 확인하기 | 장소·방향, 시간·가격, 동사, `乗る/降りる`, `へ` | 역에서 질문을 시작하는 말, 안내를 들은 뒤 답하는 말. 실제 사용 장면과 정중함을 검수한다 |

먼저 각 장면의 **일본어 대화와 한국어 대응표**를 쓴다. 문장끼리 논리적으로 이어지는지, 화자별 말투가 일관적인지, 이미 배운 표현이 자연스럽게 재등장하는지 검토한다. 단어장은 원고가 확정된 뒤 실제 등장 어휘에서 고른다. 기존 `WORDS[].f`와 문장 `s.t`를 재사용하되, 문장별 설명을 전부 쏟아내지 않고 해당 장면에 필요한 항목만 편집한다. 문화·예절 설명은 단정적인 일반화를 피하고 신뢰할 자료와 일본어 화자 검수를 거친 뒤 싣는다.

## 구현 순서와 저장 경계

1. **콘텐츠 데이터:** 기존 `SENT[5]`, `SENT[10]`과 각 문장의 `n`은 손대지 않는다. 별도 대화 데이터에 `R05`·`R10`, 화자, 발화 순서, 일본어, 한국어, 단어 키, 설명과 출처 문장 번호를 둔다. 기존 문장이나 단어를 재사용할 수 있어도 대화용 발화 식별자는 별도로 고정한다.
2. **화면·이동:** 가로 단계 목록과 PC 왼쪽 목록에 복습 항목을 지정 위치에 끼운다. 현재 화면은 번호 있는 단계와 복습 항목을 구별하는 식별자로 다룬다. 단계 번호에 `+1`을 하는 축하 화면의 「다음 단계」, 좌우 화살표 이동, 새로 열었을 때의 화면 복원도 실제 목록 순서를 따르게 한다. 기존 `ST.lv`의 숫자 뜻과 오답노트 식별자 `61`은 유지한다.
3. **완료·동기화:** `R05`·`R10`의 읽음 여부를 기존 `done`·`QDONE`·`star`와 분리해 저장한다. 복습 화면에는 `읽음`만 표시하고 `0/50`, 회차, 왕관 별을 표시하지 않는다. 기기 간 병합은 읽음 여부의 합집합으로 처리한다. 수동 진도 코드에는 선택 필드로 덧붙여 예전 `J2/J3` 코드를 읽을 수 있게 한다. 빈 값이나 예전 코드의 가져오기가 기존 진도를 지우지 않는지 확인한다.
4. **검증·배포:** 데이터 검사에 화자·번역 개수 일치, 식별자 중복, 단어 키와 미리 보는 표현 표시를 추가한다. `node tools/check.js`, `python tools/build.py`를 거친 뒤 좁은 휴대폰, iPad 가로·세로, PC에서 접기·스크롤·음성 재생·오프라인 열기를 확인한다. 기존 5·10단계 진도와 다른 기기/코드 가져오기 전후가 같은지도 확인한다.

첫 시범의 크기는 **데이터와 화면에 별도 경로를 만드는 보통 수준의 작업**이다. 특히 이동 순서와 진도 코드·동기화가 숫자 단계에 기대고 있어, 화면만 추가하는 것으로 끝나지 않는다.

## 통과 조건과 이후 판단

- `R05`와 `R10`이 각각 5·6단계, 10·11단계 사이에 보인다. 1~60단계의 번호와 기존 퀴즈 진도는 그대로다.
- 일본어 대화가 먼저 끝까지 보이고, 한국어 번역과 단어·표현은 **그 순서대로**, 각각 닫힌 채 이어진다. 번역의 화자·순서는 원문과 일치한다.
- 단어·표현 접기에 대화에서 나온 말의 뜻·쓰임, 필요한 「더 배워보기」, 검수된 예절·문화 메모가 들어간다.
- 읽음 표시가 새로고침·기기 간 동기화·코드 가져오기 뒤에도 유지되며, 예전 코드도 정상적으로 들어온다. 읽음 표시만으로 퀴즈 별이 늘지 않는다.
- 실제 휴대폰과 iPad에서 본문·번역·단어장 및 하단 영역이 겹치지 않는다.

시범을 써 본 뒤에는 대화가 자연스럽게 읽히는지, 접힌 번역·단어장을 이용하는지, 한 장면의 길이가 적절한지 확인한다. 학습 효과는 읽음 횟수만으로 판단하지 않는다. 이후 5단계 간격 확대나 회상 문제 추가 여부를 따로 결정한다.
