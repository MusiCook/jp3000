# 단계를 시나리오로 바꾸는 문제 · 검토

R1 대화 복습이 읽기 편하다는 판단에서 출발해, **번호 단계(1~60)의 50문장 나열을
장(챕터) 기반 시나리오로 바꿀 수 있는지** 따져 본 기록이다.
기능과 형태(3회차 가림·퀴즈·별·진도)는 그대로 두고 **문장을 늘어놓는 방식만** 바꾸는 안이다.

2026-10-02 검토. 아직 **결정하지 않았다.** 아래 「세 갈래」에서 고를 일이 남았다.

---

## 1. 먼저 재어 본 것

판단을 감으로 하지 않기 위해 코드와 데이터에서 숫자를 꺼냈다.

| 잰 것 | 값 | 뜻 |
|---|---|---|
| 한 문장의 가릴 자리(일본어 덩어리) | 2개 29% · 3개 47% · 4개 19% | 지금 문장은 가림 학습에 맞는 크기다 |
| 가릴 자리가 1개뿐인 문장 | 23개 (1.5%) | 짧은 발화가 늘면 이 비율이 올라간다 |
| 좌우 덩어리 수가 맞는 문장 | 94.9% (`ROUNDS.md`) | 2회차 교차가 성립하는 조건 |
| 의문문 | 244개 (16%) | 지금 문장은 **대화체가 아니다** |
| 「はい·いいえ」로 시작하는 문장 | 36개 (2%) | 응답이 거의 없다 |
| 바로 앞 질문에 답하는 짝 | 31쌍 / 1,550 | 순서만 묶어도 대화로는 안 읽힌다 |
| R1의 발화 71개 중 두 문장 이상인 것 | 54개 | 발화는 문장보다 크다. 문장 칸에 넣으면 쪼개진다 |

### 드릴 밀도 — 이것이 핵심이다

한 단계가 **같은 문형을 몇 번 반복하는지** 세어 보면 지금 구조의 의도가 드러난다.

| 단계 | 문형 종류 | 가장 많은 문형의 횟수 |
|---|---|---|
| 3 형용사로 말하기 | 11종 | `は+です` ×16 |
| 9 ます형 기초 | 17종 | `を` ×17 |
| 13 て형 만들기 | 15종 | **`を+ください` ×26** (50문장의 52%) |
| 11 복습·조사 | 22종 | `は+です` ×8 |
| **12 복습·상황** | **25종** | **`は` ×9** |

문법 단계는 한 문형을 20~26번 반복해 **몸에 붙이는 자리**다.
반면 이미 시나리오꼴인 12단계(공항 도착 → 버스 → 체크인 → 산책 → 식당 → 쇼핑)는
문형이 25종으로 가장 넓게 퍼지고 반복은 절반으로 준다.

> 장면은 문형을 **골고루** 쓰게 만든다. 드릴은 **한 문형을 몰아서** 써야 한다.
> 이 둘은 같은 50칸을 두고 다툰다. 고르는 문제이지, 겸할 수 있는 문제가 아니다.

## 2. 좋아지는 것

- **쓰는 자리가 같이 외워진다.** 「部屋は静かですか」를 형용사 예문으로 외우는 것과
  방을 안내받는 중에 묻는 말로 외우는 것은 인출 단서가 다르다. R1이 편했던 이유다.
- **듣고 답하기가 늘어난다.** 지금은 의문문 16%, 응답 2%다. 여행에서 필요한 절반은
  상대의 말을 알아듣고 받는 쪽인데 그 연습이 거의 없다.
- **지루함이 줄어든다.** 같은 문형 20개 연속 대신 장면이 전개된다.
- **3회차가 더 그럴듯해진다.** 3회차는 한국어를 보고 일본어를 만드는 회차인데,
  장면 안이면 「이 자리에서 내가 할 말」을 만드는 연습이 된다.
- **장 단위 이어 듣기**가 가능해진다. 지금 음성은 문장 하나씩이다. 장을 통째로
  들려주면 듣기 교재가 공짜로 하나 생긴다 (`VOICE.md`).
- **번호를 안 건드려도 된다.** `n`은 순서와 무관하게 진도를 기록한다
  (`sentences-01.js` 머리글). 순서를 바꿔도 진도·별·오답노트가 밀리지 않는다.
  이것이 이 변경을 **데이터 안전한 범위**에 두는 가장 큰 조건이다.

## 3. 잃는 것 · 부딪치는 것

| 문제 | 내용 | 무게 |
|---|---|---|
| **드릴 밀도** | 13단계의 `~をください` ×26을 장면으로는 못 만든다. 자연스러운 대화는 한 문형을 두세 번만 쓴다 | 큼 |
| **단계별 문법 범위** | 「해당 단계까지 나온 문법만」이 원칙이다(`PLAN.md`). R1은 5단계분을 끌어 썼는데도 「미리 보는 표현」 9개가 필요했다. 1단계 문법(명사문)만으로 자연스러운 대화는 거의 불가능하다 | 큼 |
| **맞장구가 칸을 먹는다** | 대화에는 「はい」·「そうですか」·「ありがとうございます」가 계속 필요하다. R1에서도 열 발화에 한 번쯤이다. 3,000칸의 10%면 300문장이 맞장구로 나간다 | 중 |
| **완전 중복 금지와 충돌** | 검사기가 같은 일본어 문장을 두 번 못 싣게 한다. 지금 「はい、そうです」는 1,550문장에 **딱 한 번** 있다. 대화를 60장면 쓰려면 이 규칙을 맞장구에 한해 풀어야 한다 | 중 |
| **가림이 추측으로 풀린다** | 「部屋にトイレはありますか」 다음의 「はい、[あります]」는 단어를 몰라도 맞힌다. 장면이 답을 좁힌다 — 학습에는 좋고 점검에는 나쁘다 | 중 |
| **짧은 발화** | 「おやすみなさい」처럼 덩어리가 하나면 2회차 교차가 성립하지 않는다(`ROUNDS.md` 2장). 지금 1.5%인 비율이 오른다 | 작음 |
| **장면화가 안 되는 단계** | 11단계는 조사 10개를 한자리에 모아 **비교하는** 표다. 35·36단계는 자동사/타동사 대조다. 장면으로 바꾸면 비교가 사라진다 | 중 |
| **쪽 나누기와 장 경계** | 지금은 25문장씩 두 쪽이다. 장이 쪽을 가로지르면 머리글이 잘린다. 장을 25의 약수로 맞추거나 쪽 나누기를 장 단위로 바꿔야 한다 | 작음 (화면) |
| **고쳐 쓸 양** | 1,550문장이 이미 있다. 대화로 읽히게 하려면 응답·연결을 넣어야 하고, 그때마다 한국어 해석·덩어리 짝(94.9%)·퀴즈 보기를 다시 봐야 한다 | 큼 |

화면 쪽 비용은 작다. 목록은 `buildList()`의 `map` 한 번이고, `s.lbl`처럼
문장별 표시 필드가 이미 있다. 장 머리글을 끼우는 것은 몇 줄이다.
**비용은 거의 전부 콘텐츠에 있다.**

## 4. 이미 반쯤 그렇게 설계되어 있다

`STAGES-32-60.md` 의 「한 단계의 50문장」은 배치마다 이렇게 간다.

| 배치 안 순번 | 역할 |
|---|---|
| 1~3 | 핵심 문형의 가장 짧은 예와 대조 |
| 4~10 | 사람·장소·시제를 바꾼 기본 문장 |
| 11~15 | 묻고 답하는 짝과 짧은 상황 |
| 16~22 | **실제 여행 장면과 두세 차례 오가는 대화** |
| 23~25 | 앞 문형을 섞은 마무리 |

그리고 「실전 단계인 49~60단계는 문형 대신 **장면을 중심에** 둔다」고 이미 적혀 있다.
즉 이 계획은 **드릴 → 장면**으로 기울어 가는 구조다. 지금 부족한 것은
그 장면 구간이 화면에서 **장면으로 보이지 않는다**는 점이다. 번호가 매겨진 50개 중
16~22번이라는 사실은 학습자에게 아무 신호도 주지 않는다.

## 5. 세 갈래

### 가. 묶어서 보여 주기만 (싸다)

문장을 **하나도 고치지 않고** 단계를 4~5개 장으로 묶어 머리글을 얹는다.
데이터는 문장에 `ch`(장 번호) 한 필드, 단계에 장 제목 배열만 추가한다.
배치 안 역할 구간이 이미 나뉘어 있으니 이름만 붙이면 된다.

- 비용: 화면 몇 줄 + 단계마다 장 제목 네댓 개. 31단계면 하루 거리.
- 얻는 것: 「지금 무엇을 배우는 중인지」가 보인다. 쪽 넘김이 장 단위가 된다.
- 못 얻는 것: **R1 같은 느낌은 안 난다.** 화자 교대가 없고 응답이 2%뿐이라,
  묶어 놔도 대화가 아니라 주제별 목록으로 읽힌다.

### 나. 복습 단계만 완전 시나리오로 (권한다)

복습 단계 여덟 개(11·12·23·24·35·36·47·48)를 R1처럼 장면 단위로 다시 쓴다.

- **이미 하나는 그렇다.** 12단계가 공항→버스→체크인→식당→쇼핑으로 흐른다.
  문형이 25종으로 가장 넓고 반복이 가장 적다 — 드릴을 포기해도 되는 자리라는 뜻이다.
- 복습 단계는 신출 단어를 0~2개로 억제하는 자리다(`PLAN.md`). 새 문법이 없으니
  **문법 범위 제약에도 걸리지 않는다.** R1이 성립한 조건과 같다.
- 분량 400문장. 11·35·36처럼 대조가 목적인 단계는 뒤 배치(26~50)만 장면으로 바꾸고
  앞 배치는 비교표로 남기는 식으로 반만 바꿀 수 있다.
- 부작용: 맞장구 중복 허용 범위를 복습 단계에 한해 정해야 한다.

### 다. 전면 전환 (지금은 아니다)

문법 단계까지 모두 대화로 바꾼다.

- 드릴 밀도(13단계 ×26)와 단계별 문법 범위를 동시에 포기해야 한다.
  둘은 이 교재가 「문법을 외우지 않고 문장을 읽어 익힌다」는 원칙을 지탱하는 축이다.
- 1,550문장 재작성 + 29단계 설계 변경. 2년 계획의 남은 절반을 다시 그리는 일이다.
- 49~60단계는 이미 장면 중심으로 계획되어 있으므로, 전면 전환하지 않아도
  **진행할수록 시나리오에 가까워진다.**

## 6. 권하는 것

**나 + 가.** 복습 단계를 시나리오로 바꾸고(나), 문법 단계는 장 머리글만 얹어(가)
지금 무엇을 배우는 중인지 보이게 한다. 드릴이 필요한 자리는 드릴로 남긴다.

이 조합이면 학습자는 **드릴 다섯 단계 → 장면 한 단계**를 번갈아 만난다.
R1을 5·6단계 사이에 끼운 것과 같은 리듬이고, R-복습을 늘리는 쪽과도 겹치지 않는다
(`DIALOGUE-REVIEW-PLAN.md`의 「다음 복습 구간을 만들 때」).

### 먼저 확인할 것

판단을 더 좁히려면 **12단계와 13단계를 나란히 써 보는 것**이 가장 빠르다.
12단계는 이미 장면이고 13단계는 드릴 ×26이다. 같은 3회차를 돌려 보고
어느 쪽이 잘 남는지 보면, 위의 표보다 정확한 답이 나온다.

## 안 되는 것 · 하면 안 되는 것

- **문장 번호 `n`을 다시 매기지 않는다.** 순서는 바꿀 수 있지만 번호는 못 바꾼다.
  진도·별·오답노트·수동 진도 코드가 모두 이 번호에 걸려 있다.
- **「미리 보는 표현」으로 문법 범위를 넘지 않는다.** R1은 번호 없는 읽기 자료라
  미학습 표현을 설명으로 밝히고 넘어갈 수 있었다. 번호 단계의 문장은 가림·퀴즈·
  오답노트에 들어가므로 같은 수를 쓸 수 없다.
- **장면을 이유로 틀린 문장이나 어색한 한국어를 싣지 않는다.** 흐름이 급해 보여도
  규칙은 `PLAN.md` 쪽이 이긴다.
