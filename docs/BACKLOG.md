# 남은 일

여기저기 흩어져 있던 「남은 일」을 한 곳에 모은 것.
**다음에 무엇을 할지는 여기서 고른다.**
끝낸 것은 지우고 `CHANGELOG.md` 로 옮긴다.

무게 — ★★★ 크다 · ★★ 보통 · ★ 작다

---

## A. 지금 하는 일

### A-1. 문장 음성 ★★★
`VOICE.md` 참고. 1단계 50문장 × 두 목소리까지 구웠고 앱에는 안 붙였다.

1. **포맷을 정한다** — WAV 그대로면 3,000문장에 880MB. Opus/MP3 로 1/8~1/10
2. **어디에 둘지 정한다** — 저장소 안 / 밖. Pages 권고 한도 1GB
3. **앱에 붙인다** — 지금 `.spk` 단추는 브라우저 `speechSynthesis` 를 부른다.
   구운 파일이 있으면 그것을, 없으면 지금대로 부르게 겹치면 된다
4. **오프라인 정책** — 서비스 워커가 소리까지 담을지, 단계별로 나눠 받을지
5. 나머지 30단계 1,500문장 굽기 (돈과 시간이 든다. 위 넷을 정한 뒤에)

### A-2. 「더 배워보기」 살리기 ★★★
`NOTES-PLAN.md` 참고. **자료는 이미 있는데 화면에 안 나온다.**

1. **필터를 연다** (코드만, 데이터 안 건드림) — `NPRIO` 를 「고르는 방식」에서
   「줄 세우는 방식」으로. 590문장이 즉시 살아난다
2. 문장 설명(`t`)의 갈래 이름을 못 박는다 — 쓰는 자리 / 실제로는 / 정중한 정도 /
   바꿔 말하기 / 주의
3. 1~2단계 100문장에 본보기를 채우고 화면으로 확인한 뒤 배치로 확장

### A-3. 32~60단계 문장 1,450개 ★★★
가장 큰 덩어리이자 **가장 큰 병목**. 한 사람이 손으로 쓴다.

---

## B. 구조

### B-1. `src/chunk.js` 로 덩어리 나누기를 빼낸다 ★★
검사기가 좌우 덩어리 짝을 못 본다. 코드가 `trainer.html` 안에 있고 검사기는
`src/*.js` 만 읽기 때문이다. 빼내면 앱과 검사기가 같은 코드를 쓴다.
**문장 전수 검토 전에 해 두는 것이 좋다.**

### B-2. 「동작」 그룹이 375개로 지나치게 크다 ★★
퀴즈 오답 보기가 이 그룹에서 뽑히는데, 너무 커서 엉뚱한 보기가 섞인다.
쪼개고, 반대로 너무 작은 그룹은 합치거나 단어를 늘린다. (`REVIEW.md` B-2)

### B-3. 오답노트를 틀린 방향으로 먼저 내기 ★
지금은 한 말을 두 번(뜻·일본어) 낸다. 틀린 방향을 먼저 내려면 `QSTAT` 에
방향을 기록해야 한다 — 지금은 `{o, x}` 뿐이다. (`ROUNDS.md` 10장)

### B-4. 부분 렌더링 ★
단계를 옮길 때마다 25문장을 다시 그린다. 3,000문장이 다 차고 체감되면 손본다.

### B-5. 0단계(가나 표) 상태가 저장되지 않는다 ★

## C. 콘텐츠 품질

### C-1. 원어민 검수 ★★★
AI 가 만든 문장 중 문법은 맞아도 **실제로 쓰지 않는 표현**이 있을 수 있다.
「私は観光です」 같은 것. 표본 점검이 필요하다.

### C-2. 짝이 안 맞는 79문장 ★★
좌우 덩어리 수가 달라 2회차 교차 가림이 통짜로 떨어지는 문장들.

---

## D. 나중에 / 판단이 필요한 것

### D-1. 말하기 ★★★
발음 판정이 없다. 목표가 「여행에서 말하기」인데 입이 빠져 있다.
브라우저 음성 인식은 기기를 타고, 판정 기준을 세우기도 어렵다. **아직 길이 안 보인다.**

### D-2. 진도 자동 동기화
지금은 Firebase 로그인 아니면 코드 복사. 서버를 붙일지.

### D-3. 파일 분리
3,000문장이 차서 1MB 를 넘으면 `notes.js` 등으로 나눈다.

### D-4. 맞힘 표시를 어디까지 남길 것인가
한 화면 안에서만(지금) / 앱을 닫아도 유지 / 일정 시간 뒤 초기화.
두 번째는 편하지만 다시 풀 기회가 사라진다. 지금은 첫 번째를 두되
**「이 단계 다시 풀기」 단추**를 두는 정도가 적당해 보인다. (`REVIEW.md` E)

## E. 하지 않기로 한 것

지우지 않고 남겨 둔다. 같은 생각을 또 하지 않으려고.

|---|---|
| 단어장 | 문장에서 떼어낸 낱말 암기는 이 교재의 원칙과 어긋난다. 「가림」과 오답노트로 대체 |
| 런타임 AI 호출 | 정적 배포라 키를 숨길 데가 없고 오프라인에서 못 쓴다. 빌드 타임에 미리 만든다 |
| 스트릭·리그·하트 | 끝이 정해진 교재라는 성격과 어긋난다. 매일 열게 만드는 힘은 얻지만 값이 크다 |
| 빠르기를 지시문으로 조절 | 두 번 해봤고 두 번 다 실패했다. 인물까지 바뀐다 (`VOICE.md` 3장) |
