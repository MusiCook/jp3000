# 「더 알아보기」 개선 계획

---

## 1. 지금 상태

| 항목 | 값 |
|---|---|
| 문장 | 1,550개 |
| 설명이 붙은 문장 | 313개 (20%) |
| 설명 길이 | 평균 32자 (14~54자) |
| 표시 방식 | 문장 아래 접기/펴기 |

**단계별로 8~15개**씩만 붙어 있습니다. 문법이 처음 나오는 자리에만 한 줄씩 달아둔 상태입니다.

### 지금 설명의 문제

```
13-001  ちょっと待ってください。
        「て형 + ください」로 부탁한다. 待つ → 待って.
```

**규칙만 있고 쓸 자리가 없습니다.** 언제 쓰는지, 다른 말과 어떻게 다른지, 실수하기 쉬운 곳은 어디인지가 빠져 있습니다.

또 **80%의 문장에는 아무 설명이 없습니다.** 눌러도 나올 게 없어 「더 알아보기」 버튼 자체가 안 보입니다.

---

## 2. 무엇을 담을 것인가

한 문장에 다 넣으면 길어져 안 읽습니다. **필요한 것만 골라 담는 구조**로 갑니다.

### 다섯 갈래

| 갈래 | 언제 넣나 | 예 |
|---|---|---|
| **문형** | 새 문법이 처음 나올 때 | 「て형 + ください」로 부탁한다 |
| **주의** | 한국어와 어긋나 틀리기 쉬울 때 | 会う는 を가 아니라 に를 쓴다 |
| **바꿔 말하기** | 같은 뜻의 다른 표현이 있을 때 | 더 정중하게는 「~ていただけますか」 |
| **쓰는 자리** | 실제 상황이 그려질 때 | 택시에서 그대로 쓴다 |
| **곁들임** | 함께 알아두면 좋은 것 | 반대는 「引く」. 문에 붙어 있다 |

**문장마다 1~3갈래**만 답니다. 다 채우지 않습니다.

### 갈래별 분담 원칙

- **문형**은 단계 첫 등장에만. 같은 문형이 열 번 나오면 첫 번째에만 답니다
- **주의**는 한국어 화자가 실제로 틀리는 것만. "일본어는 어순이 다르다" 같은 일반론은 넣지 않습니다
- **바꿔 말하기**는 정중도 차이가 있을 때 유용합니다
- **쓰는 자리**는 여행에서 실제로 마주치는 장면일 때만
- **곁들임**은 짝·반대말·간판 표기처럼 덤이 될 때만

## 2-2. 낱말 정보를 함께 담는다

문장 설명과 별개로, **그 문장에 쓰인 낱말의 활용형·반대말**을 함께 보여줍니다.
사전에 이미 들어 있으므로 **자동으로 끌어옵니다. 따로 쓸 필요가 없습니다.**

### 재고

| 그룹 | 항목 수 |
|---|---|
| 형태 (ます·ません·ました·て형·반말) | 801 |
| 반대말 | 72 |
| 짝이 되는 말 (자동사/타동사) | 53 |
| 짝 (계열 묶음) | 43 |
| 뜻 구분 | 85 |

문장당 이런 정보를 가진 낱말은 **1~2개가 대부분**(1,349문장)이고, 3개 이상은 180문장입니다.

### 문제: 그대로 넣으면 길어진다

```
30-001  日本語が上手ですね。
  [日本語]  짝: 일본어 / 한국어 / 영어
  [上手]    짝: 잘함 / 서투름
  [です]    형태: です / じゃないです / でした / じゃなかったです
  [ね]      짝: ね / よ / よね
```

네 낱말이 다 나와 팝업이 화면을 넘깁니다.

### 골라내는 규칙 (실측으로 확정)

| 정보 | 언제 넣나 |
|---|---|
| 반대말 · 짝이 되는 말 · 뜻 구분 | **늘 넣는다.** 볼 때마다 값어치가 있다 |
| 형태 (ます·ました·て형…) | **처음 나올 때만.** 매번 반복하면 안 읽는다 |
| `です`·`ください`·`ます` 같은 문형 조각 | **넣지 않는다.** 문장 설명에서 다룬다 |

한 문장에 **최대 2낱말**까지.

이 규칙으로 돌려본 결과입니다.

```
낱말이 붙는 문장   811 / 1,550 (52%)
  1낱말   641문장
  2낱말   170문장
  없음    739문장
```

앞 단계는 새 낱말이 많아 자주 붙고, 뒤로 갈수록 반대말·짝이 있는 것만 남습니다.
**적당한 밀도**입니다.

이렇게 하면 위 예는 이렇게 줄어듭니다.

```
30-001
  [上手]  잘함 ↔ 下手 서투름
  [ね]    ね 동의를 구함 · よ 알려줌 · よね 확인
```

### 표시

문장 설명 아래에 **「이 문장의 말」** 이라는 갈래로 붙입니다. 낱말을 누르면 지금처럼
낱말 툴팁이 따로 열리므로, 여기서는 **한두 줄 요약만** 보여줍니다.

## 3. 어떻게 보여줄 것인가

### 접기 → 팝업

지금은 펼치면 아래 문장이 밀려 읽던 자리를 잃습니다. 여러 개 펼치면 목록이 흐트러집니다.

**단어 툴팁과 같은 팝업**으로 바꿉니다. 화면이 안 밀리고 조작이 일관됩니다.

### 팝업 안 구성

```
┌─────────────────────────┐
│ ちょっと待ってください。      │  ← 문장 (후리가나 포함)
│ 잠깐 기다려 주세요           │  ← 해석
├─────────────────────────┤
│ 문형                      │
│ 「て형 + ください」로 부탁한다  │
│ 待つ → 待って              │
├─────────────────────────┤
│ 바꿔 말하기                │
│ 待っていただけますか         │  더 정중              │
│ ちょっと待って              │  반말                 │
├─────────────────────────┤
│ 쓰는 자리                  │
│ 줄 서서 순서를 기다릴 때      │
├─────────────────────────┤
│ 이 문장의 말                │  ← 사전에서 자동으로 가져옴
│ 待つ  待ちます · 待ちました   │
│       待って · 待った        │
└─────────────────────────┘
```

단어 툴팁이 이미 **그룹 + 항목** 구조라 같은 형식을 씁니다. 만들어 둔 스타일을 그대로 재사용합니다.

## 4. 데이터를 어떻게 담을 것인가

### 지금

```js
{ n:1, j:[...], k:[...], t:"「て형 + ください」로 부탁한다. 待つ → 待って." }
```

문자열 한 줄입니다. 갈래를 나눌 수 없습니다.

### 바꿀 형태

```js
{ n:1, j:[...], k:[...],
  t:[
    ["문형", "「て형 + ください」로 부탁한다", "待つ → 待って"],
    ["바꿔 말하기", "待っていただけますか", "더 정중"],
    ["쓰는 자리", "줄 서서 순서를 기다릴 때", ""]
  ] }
```

**단어 툴팁과 같은 3칸 구조**입니다. 렌더 코드를 공유할 수 있습니다.

### 기존 313개는

문자열도 그대로 받아들이게 만듭니다. `t`가 문자열이면 `[["설명", 그대로, ""]]`로 감쌉니다. **한꺼번에 고치지 않아도 됩니다.**

---

## 5. 파일을 나눌 것인가

### 계산

```
설명 200자 × 3,000문장 = 약 600KB
현재 파일 434KB → 1MB 넘김
```

### 판단

**지금은 나누지 않습니다.**

- 1,550문장 시점에서는 설명을 다 채워도 700KB 정도입니다
- 서비스 워커가 캐시하므로 두 번째부터는 받지 않습니다
- 파일을 나누면 배포 파일이 늘고 관리가 번거로워집니다

**3,000문장이 차서 1MB를 넘으면** 그때 `notes.js`로 분리합니다. 구조는 지금 잡아두되 실행은 미룹니다.

## 6. 어디부터 채울 것인가

1,550문장에 다 다는 것은 무리입니다. **가치 순으로** 갑니다.

| 순서 | 대상 | 개수 | 이유 |
|---|---|---|---|
| 1 | 기존 313개를 갈래 구조로 | 313 | 형식을 먼저 확정 |
| 2 | 각 단계 문법 첫 등장 | 약 120 | 새 문형은 반드시 설명 |
| 3 | 한국어와 어긋나는 곳 | 약 150 | 틀리기 쉬운 자리 |
| 4 | 실전 장면 (여행 직결) | 약 200 | 실제로 쓸 문장 |
| 5 | 나머지 | — | 필요할 때만 |

**전부 채우지 않는 것이 원칙입니다.** 설명이 없는 문장은 「더 알아보기」 버튼이 안 나옵니다. 그게 낫습니다. 모든 문장에 버튼이 있으면 눌러볼 이유가 없어집니다.

---

## 7. 쓰는 규칙

앞서 문장을 만들 때 지킨 원칙을 그대로 이어갑니다.

- **한 갈래 두 줄을 넘기지 않는다.** 길면 안 읽습니다
- **틀린 일본어를 본문에 싣지 않는다.** 「~는 틀린 말이다」처럼 설명 안에서만 언급합니다
- **문법 용어를 최소로.** 「て형」「보통형」처럼 이미 단계에서 배운 말만 씁니다
- **한국어와 다른 지점을 짚는다.** 같은 것은 설명하지 않습니다
- **여행에서 쓸 자리가 있으면 적는다.** 없으면 억지로 만들지 않습니다

## 8. 순서

```
1단계  팝업으로 바꾸기 + 갈래 구조 받아들이기   (코드)
2단계  기존 313개를 갈래로 정리                (내용)
3단계  1~5단계 문장에 설명 채우기               (내용)
4단계  나머지 단계로 확장                      (내용)
```

**1단계를 먼저 하고 2단계 결과를 보신 뒤** 방향을 정하는 게 안전합니다. 갈래 구성이 마음에 안 들면 그때 고치는 편이 1,000개를 만든 뒤 고치는 것보다 낫습니다.
