# 바뀐 것

새로 시작할 때 맥락을 잡기 위한 기록. 최근 것이 위에 온다.

## 회차 학습 · 4단계 (회차를 마쳤을 때)

- 회차를 마치면 축하 팝업이 뜬다. 큰 별이 튀어오르고, 얻은 별 개수와
  다음 회차가 무엇을 가리는지 알려 준다
- 색종이. 라이브러리 없이 캔버스에 직접 그린다. 조각 90개, 약 2.6초.
  색은 앱 팔레트 그대로 — 금색·초록·연초록·크림
- 축하음. 이미 있던 `tone()` 으로 4음 아르페지오. 효과음이 「없음」이면 안 난다
- 팝업을 닫으면 **별이 위쪽 왕관 자리로 날아가 박힌다.**
  날아오기 전까지 그 자리는 비워 두었다가(`data-hold`), 착지하면 채우고 한 번 튄다
- 별 채우는 차례를 왼쪽 → 오른쪽 → 가운데로 바꿨다.
  가운데가 가장 높이 솟아 있어 마지막에 채워야 왕관이 완성돼 보인다.
  PC 세로 목록은 한 줄이라 `order` 로 자리를 바꿔 왼쪽부터 차 보이게 했다
- 「움직임 줄이기」를 켠 기기에서는 색종이와 날아가는 별을 건너뛰고
  팝업만 조용히 띄운다. 별은 그대로 채워진다

## 회차 학습 · 3단계 (별과 손질)

- 단계 동그라미 위에 별 세 개를 왕관처럼 얹었다.
  기본은 빈 별 세 개이고, 회차를 마칠 때마다 왼쪽부터 금색으로 찬다
  - 가로 내비는 `overflow-x` 때문에 위로 삐져나온 것이 잘린다.
    `.levels` 의 위쪽 여백을 16px 로 늘려 그 안쪽에 별을 그린다
  - 유니코드 ★ 는 기기마다 모양이 달라 SVG 로 그렸다
  - PC 왼쪽 세로 목록에는 글줄 옆에 나란히 붙인다
- 완료 표시를 「완료」 글자에서 초록 동그라미 체크로 바꿨다
- 「더 배워보기」를 접기/펴기처럼 보이던 것에서 테두리 있는 단추로 바꾸고,
  팝업을 화면 가운데로 옮겼다. 쓰지 않던 `.tbody2` CSS 를 지웠다

## 회차 학습 · 2단계 (회차 판정과 교차 가림)

- 한 단계를 세 번 돈다. 머리띠에 「1회차」가 금색으로 뜬다
  - 1회차 한국어를 가린다 · 2회차 좌우를 번갈아 가린다 · 3회차 일본어를 가린다
- 2회차 교차는 좌우 덩어리 수가 같은 1,471문장에서 한다.
  수가 다른 79문장은 한쪽만 통짜로 가린다.
  짝을 모르는 채 교차하면 가린 자리의 단서까지 같이 가려져 풀 수가 없다
- 어느 쪽부터 가릴지는 문장 번호로 정한다. 다시 열어도 같은 자리가 가려진다
- **완료는 손으로 하지 않는다.** 그 문장의 가린 자리를 다 맞히면 완료가 된다
- 단계를 다 채우면 별이 하나 붙고 다음 회차로 넘어간다.
  별은 「다시 풀기」로도 지워지지 않는다
- 왼쪽으로 밀어 완료하던 것을 뺐다. 오른쪽으로 미는 북마크는 그대로다
- 보기 모드 단추(눈 아이콘)를 감췄다. 코드는 남겨 두었고,
  CSS 한 줄(`#bEye{display:none}`)을 지우면 「모두 보기」가 가림 끄기가 된다

## 회차 학습 · 1단계 (저장 구조와 덩어리 나누기)

**덩어리 나누기를 고쳤다** — 좌우 짝이 맞는 문장 84.3% → 94.9%

- 단위는 앞이 숫자일 때만 앞말에 붙인다.
  「本」이 단위(자루)와 명사(책)를 겸해서 「かばんに / 本が」가 뭉쳐 있었다.
  한국어 「개」도 같은 이유로 「공원에 / 개가」가 뭉쳤다
- `GLUEJP` 에서 ています·ていただけますか 계열 13개를 뺐다.
  한국어가 「말해 / 주시겠습니까」 두 덩어리인데 일본어만 한 덩어리였다. 164문장
- 28-11 이 「3」 대신 「씨」 키를 쓰고 있었다 (`san` → `san3`)
- 남은 79문장은 문장 데이터 쪽 문제라 전수 검토로 미룬다

**저장 구조** — 회차를 담을 수 있게 바꿨다. 화면에는 아직 안 나온다

- 맞힌 자리(`QDONE`)의 값을 회차 비트로. 1회차=1, 2회차=2, 3회차=4
- 완료 문장을 회차별로 세 벌 (`ST.done[회차][단계]`)
- 별(`ST.star`)과 현재 회차(`ST.r`)를 따로 저장.
  별은 「다시 풀기」로도 지워지지 않아야 하므로 계산으로 뽑지 않는다
- 진도 코드 `J2` → `J3`, 퀴즈 코드 `Q1` → `Q2`. 옛 코드는 그대로 읽힌다
- 옛 진도는 1회차 완료분으로 옮기고, 다 끝낸 단계에는 별 하나를 준다
- 「이 단계 다시 풀기」는 지금 도는 회차만 되돌린다

## 다크 모드

- 설정 첫 항목에 「화면」 추가 — 기기 설정 / 밝게 / 어둡게
- 「기기 설정」은 폰·PC의 다크 모드를 따라가고, 도중에 바뀌면 같이 바뀐다
- CSS에 직접 박혀 있던 색 51군데를 변수로 끌어올렸다.
  어두운 판은 `:root[data-theme="dark"]` 한 곳에서만 값을 갈아 끼운다
- 칠하는 초록(`--green`)과 글자로 쓰는 초록(`--acc`)을 갈랐다.
  어두운 판에서는 글자 쪽만 밝아진다. 벽돌색도 `--seal` / `--acc-r` 로 같은 방식
- 머리띠와 팝업(`--band`)은 두 판 모두 짙은 초록 그대로 둔다

- 정답을 고를 때마다 PC에서 화면이 조금씩 밀려 올라가던 문제.

  넓은 화면에서도 돌고 있었다

  문법은 맞지만 입국심사에서 실제로 쓰지 않고,

## 구조 개선 (31단계 시점)

**보기 생성**
- 의미 그룹 36개를 사전에 붙여, 같은 갈래에서 보기를 뽑는다
- 「말+조사」를 한 덩어리로 다루고, 문장에 실제로 나온 763종을 먼저 쓴다
- 서술은 어미를 갈아 끼운다 (않습니다 → 않았습니다 / 않겠습니다)
- 같은 뜻 짝(お名前/名前 등)은 어느 쪽을 골라도 정답으로 인정하고 차이를 알려준다

**화면**
- 스타벅스 팔레트로 전면 교체 (하우스 그린 · 크림 · 리저브 골드)
- 상단 메뉴를 아이콘으로 통일, 헤더와 단계 내비를 함께 고정
- 한 단계를 25문장씩 두 쪽으로
- 패드·PC 대응 (글자 확대 / 왼쪽 세로 단계 목록 / 키보드)

**학습**
- 표시 모드 3종 (한국어만 / 일본어만 / 모두 보기)
- 퀴즈: 맞히면 같은 문장의 다음 자리로 이어지고, 끝에서 앞으로 돈다
- 오답노트를 카드형 복습으로. 0/3/7/21일 간격 반복
- 「더 배워보기」를 팝업으로. 그 문장을 다 맞혀야 열린다
- 가나 표(0단계), 효과음 5종, 통계 차트

**앱**
- PWA — 홈 화면 설치, 오프라인 실행, 갱신 알림
- 파일명을 `jp3000.html` 로
